# College Money Tracker

## About
College Money Tracker is a Python program I created to help college students organize their money. The program lets users decide how much money they want to save and invest, then calculates how much they have left to spend.

## Features
- Enter your current amount of money
- Choose how much money to put into savings
- Choose how much money to invest
- Calculate how much money is left for spending
- Accept numbers with commas and decimals
- Warn the user if they try to use more money than they have

## What I Learned
While building this project, I practiced using Python variables, user input, calculations, floats, and if/elif/else statements. I also learned how to format money and handle different types of user input.
